# WWW: World Wide Web
---
### Что такое Интернет?
- Сеть, где устройства обмениваются данными, используя **Интернет-протокол (IP)**
- **IP-адрес** — идентификатор сетевого интерфейса:
  - IPv4: 4 байта (например, `10.254.69.23`)
  - IPv6: 16 байт
- **Локальный IP-адрес** — адрес интерфейса в локальной сети (например, `192.168.1.5`)
- **Глобальный IP-адрес** — адрес, используемый для связи с Интернетом
---

- Команда `ipconfig` (или `ifconfig`) покажет локальный адрес
- Сервис вроде `www.whatismyip.com` покажет внешний IP-адрес
> 💡 **Важно (NAT):** Локальные адреса не маршрутизируются в интернете. Домашний роутер обычно использует **NAT** (трансляцию сетевых адресов): при выходе в Интернет он преобразует локальный адрес в внешний адрес роутера (провайдера).

---
### Интернет как инфраструктура
- **Интернет** — глобальная сеть взаимосвязанных компьютерных сетей, объединяющая множество устройств и сетей в общее информационное пространство.
- Интернет предоставляет инфраструктуру для прикладных сервисов различного назначения.
- Один из самых популярных прикладных сервисов Интернета — **Всемирная Паутина (World Wide Web — WWW)**.



---
### Символьные имена (DNS)
- Запоминать IP-адреса неудобно. Для этого служит **Domain Name System (DNS)** — распределённая система имён, позволяющая находить сетевые ресурсы по символьным именам.
  - `wikipedia.org` → IP-адрес
  - `sites.google.com` → IP-адрес
- DNS хранит не только IP-адреса, но и другие типы записей (`A`, `AAAA`, `MX`, `CNAME`, `TXT` и др.).
- **Локальные соответствия имён адресам** могут задаваться непосредственно в операционной системе.
  - В Windows они могут храниться в файле: `C:\Windows\system32\drivers\etc\hosts`

### World Wide Web (WWW)
- **WWW** (web, веб, Всемирная Паутина) — распределённая информационная система, предоставляющая доступ к гипертекстовым документам и другим ресурсам по сети.
- Основным протоколом взаимодействия в WWW является **HTTP**.
- WWW построена на **клиент-серверной архитектуре** и использует инфраструктуру Интернета для взаимодействия между клиентом и сервером.

### Архитектура веб-сервиса
Основные технологии WWW:
- **URI / URL** — способы идентификации и адресации ресурсов.
  - *URI* (идентификатор) — общий способ идентифицировать ресурс.
  - *URL* — разновидность URI, указывающая способ доступа к ресурсу и его местоположение.
- **HTML** — язык разметки веб-документов.
- **HTTP** — протокол передачи гипертекста и других данных.

---
### Архитектура веб-сервиса

- **Серверные технологии** — CGI, серверные языки программирования, серверы приложений и т.д.
- Эти технологии стандартизируются разными организациями. Например, URI — в стандартах IETF, а современный HTML развивается как **WHATWG HTML Living Standard**.

### URL (Унифицированный локатор ресурсов)
- **URL** — распространённый способ записи адреса ресурса в WWW и сети Интернет.
- Общий синтаксис URI стандартизирован в **RFC 3986**.
- URL имеет гибкую и расширяемую структуру.
- Для записи URI используется ограниченный набор символов с правилами кодирования.

![Анатомия URL](https://commons.wikimedia.org/wiki/Special:FilePath/URL_structure.jpg)

---
### Структура URL
Общий вид адреса:
<схема>://<пользователь>:<пароль>@<хост>:<порт>/<путь>?<параметры>#<фрагмент>

- **схема** — способ обращения к ресурсу (`http`, `https`, `ftp`, `mailto`, `file` и т.п.).
- **пользователь:пароль** — данные для авторизации (необязательно; в современных URL обычно не используются).
- **хост** — доменное имя или IP-адрес сервера.
- **порт** — порт для подключения (если не указан, используется стандартный для конкретной схемы, например 80 для HTTP).
- **путь** — уточняющая информация о ресурсе.
- **параметры (query)** — дополнительные данные запроса.
- **фрагмент** — указание на часть ресурса.

---
### Примеры URL
- `http://example.com` — запрос стартовой страницы по умолчанию
- `http://www.example.com/site/map.html` — запрос страницы в указанном каталоге
- `http://example.com:81/script.php` — подключение на нестандартный порт
- `http://example.org/script.php?key=value` — передача параметров скрипту
- `ftp://user:pass@ftp.example.org` — авторизация на FTP-сервере
- `http://192.168.0.1/example/www` — подключение по IP-адресу
- `file:///srv/www/htdocs/index.html` — открытие локального файла

### HTML (HyperText Markup Language)
- Стандартный язык разметки документов во Всемирной паутине.
- Большинство веб-страниц использует HTML.
- HTML интерпретируется браузером и преобразуется в структуру документа, которую браузер отображает пользователю.
- Изначально HTML создавался как средство **структурирования** документов без жёсткой привязки к конкретному способу воспроизведения.
> ⚠️ *Исторически HTML развивался на основе SGML. Современный HTML является самостоятельным стандартом — **WHATWG HTML Living Standard**.*

### HTTP (HyperText Transfer Protocol)
- Протокол передачи гипертекста и других данных в WWW.
- HTTP/1.1, HTTP/2 и HTTP/3 — разные версии протокола с общей базовой семантикой, но разными механизмами передачи данных.
- Типичный **клиент-серверный протокол**: клиент отправляет запрос, сервер возвращает ответ.
- HTTP позволяет передавать различные типы данных: HTML, изображения, видео, JSON и т.д.
- В HTTP/1.x сообщения имеют текстовое представление, а HTTP/2 и HTTP/3 используют бинарное представление протокольных сообщений.

### Статический vs Динамический веб
- **Статический веб:** Сервер отдаёт заранее подготовленный ресурс (например, `.html`) практически без изменения содержимого.
- **Динамический веб:** Содержимое страницы генерируется **«на лету»** в момент запроса. Серверная программа может собрать HTML из шаблонов, получить данные из базы данных, учесть параметры запроса или профиль пользователя.

*Для реализации динамического веба используются серверные программы, модули, CGI, серверы приложений и другие серверные технологии.*

---
### Серверные расширения
- Для создания динамических сайтов одного HTTP недостаточно — сервер должен уметь выполнять или вызывать программный код.
- Существуют различные механизмы доступа к программам на стороне веб-сервера (интерфейсы и модули расширения).
- Эти программы могут генерировать HTML "на лету" и передавать результат веб-серверу, который отправляет его клиенту.
- Исторически одним из первых стандартных механизмов был **CGI** (Common Gateway Interface).



---
### Программное обеспечение: Веб-серверы
- **Веб-сервер** — сетевое приложение, обслуживающее HTTP-запросы от клиентов (браузеров и других HTTP-клиентов).
- Принимает запросы и возвращает ответы (HTML, изображения, файлы, медиа и другие данные).
- Среди широко используемых веб-серверов: **Apache**, **Nginx**, **IIS**.
  - 💡 **Почему популярен Nginx?** Nginx использует *событийно-ориентированную архитектуру*, что позволяет эффективно обрабатывать большое количество одновременных соединений. Apache поддерживает несколько моделей обработки соединений, включая процессную и многопоточную.

---
### Программное обеспечение: Браузеры
- **Браузер (web-browser)** — клиентское приложение для доступа к веб-серверам и просмотра веб-страниц.
- Основным протоколом WWW является HTTP; браузеры также поддерживают другие схемы и протоколы (например, `file`, исторически `ftp`).
- Первые HTTP-клиенты были консольными и работали в текстовом режиме (lynx, w3m, links).
- **NCSA Mosaic** был одним из первых широко известных графических веб-браузеров и оказал большое влияние на развитие WWW. Его разработчики — Марк Андриссен и Эрик Бина.
